1. Pseudokód / Struktura Algoritmus

Podporované termíny pseudokódu

  • ALGORITMUS název(...): — hlavička algoritmu
  • POKUD / IF — podmínka
  • JINAK / ELSE — alternativní větev
  • DOKUD / WHILE — podmíněný cyklus
  • PRO prvek V kolekce / FOR prvek IN collection — průchod kolekcí
  • PRO i OD začátek DO konec / FOR i FROM start TO end — počítaný cyklus (šestiúhelník)
  • VRAT hodnota / RETURN value — předání výsledku funkce (rovnoběžník)
  • VYPIS hodnota / WRITE value — tisk hodnoty
  • Bloky pište s dvojtečkou a odsazujte; ostatní řádky se zobrazí jako kroky.
  • Neznámá velká slova na začátku řádku jsou podtržena červeně; upozornění je pouze orientační.
